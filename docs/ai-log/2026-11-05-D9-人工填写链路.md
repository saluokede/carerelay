# D9 · 人工填写链路（本地模式下的"最后一公里"）

> 触发：用户看完"当前未配置模型 Key，已切到本地模式：请手工填写结构化档案"这句提示后回了一句「没有人工填写方法」。
> 这句话点出了一个真问题：**降级路径说了要人填，却没给填的地方。**

## 一、这次到底坏了什么

| # | 现象 | 根因 |
|---|---|---|
| 1 | 提示"请手工填写"，页面上没有任何可填控件 | 只有模型抽取这一条写入路径，没有人工写入接口，也没有编辑表单 |
| 2 | 抽取结果里"出院带药 0 种"、诊断空白（即使模型给了） | 后端字段叫 `ExtractResult.data`，前端接口声明成 `structured`，`structured` 永远是 `undefined` |
| 3 | "饮食与活动""复诊与红线"常年为空 | 后端按提示词原样存 snake_case（`activity_limit`、`red_flags`），前端按 camelCase 读 |
| 4 | 手填一次后，原来抽好的药单/管路/伤口消失 | 保存用的是"整份覆盖"，没提交的字段被当作空值写回 |
| 5 | 手填后仍显示"置信度偏低（< 0.6）：diet、hospital…" | 模型置信度留在库里，人工改过的档案不该再谈模型置信度 |
| 6 | 一条诊断"高血压 3 级"被拆成三条 | 编辑器把逗号文本按 `[，,、\s]+` 拆，中文短语里的空格也当成分隔符 |

## 二、改法

**后端** `backend/src/main/java/com/carerelay/discharge/DischargeExtractService.java`
- 抽出 `applyData(record, json)`，抽取与人工填写共用一份字段映射（注释写明"避免两处字段名漂移"）。
- 新增 `saveManual(userId, recordId, json)`：`PUT /api/v1/discharge/{id}/structured`，状态置 `REVIEWED`，写 `DISCHARGE_MANUAL_EDIT` 审计。
- **合并而非覆盖**：先用 `rebuildData(existing)` 把库里旧档案拼回 JSON，再把提交上来的键覆盖上去；`confidence` 置 `{}`（用 null 会被 `updateById` 跳过，删不掉旧值）。
- 缺失字段改为对**合并后**的数据算，避免"我只改了药单"却报告"缺主要诊断"。

**前端**
- `api/index.ts`：`ExtractResult.data`（与后端同名）、`normalizeDischargeData()` 统一 snake→camel、新增 `saveDischargeStructured()`。
- 新组件 `components/DischargeEditor.vue`：医院/科室/入出院日期、主要诊断 + 其他诊断、可增删的用药表格、管路/饮食/活动/手术、伤口、复诊、红线表格；`toTextArray` 改为只按 `，、；\n` 拆；其他诊断自动剔除主要诊断。
- `views/DischargeImportView.vue`：进页面自动读最新一条出院记录；`MANUAL` 状态自动打开编辑面板；「手工填写 / 修订」按钮随时可进；保存后重算评分卡并提示。

## 三、实测

| 步骤 | 结果 |
|---|---|
| `PUT /discharge/5/structured` 只传 `medications` | `code=0`，诊断 3 条、医院日期保持原样，药单变 3 条（合并生效） |
| 再传 `activity_limit` | `status=REVIEWED`，`confidence` 键数 0，药单/诊断未丢 |
| 浏览器：`/elders/4/import` | 页面自动带出"已人工复核"状态与「手工填写 / 修订」按钮 |
| 打开编辑器 | 医院/科室/日期/主要诊断/3 条用药全部回填；其他诊断不再重复主要诊断 |
| 点「保存并重新评估」 | 绿色提示"已保存人工填写的档案，并按最新内容重算了风险评分卡"，评分卡由 4 分更新为新值 |

## 四、教训

1. **降级路径必须闭环**。说"请手工填写"就必须同时给表单、给保存接口、给保存后的状态，否则就是一句空话。
2. **字段名是最容易烂的地方**。`data` / `structured` 这种叫法不统一，TS 不会报错（可选字段），页面只会"安静地显示空"。
3. **写接口要区分 patch 与 replace**。人改两项，不该把另外八项清空。
4. **中文文本不能按空格拆词**。"高血压 3 级""低盐低脂饮食 2 周"都会被拆坏。
