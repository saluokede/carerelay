## 4. 踩坑与修正（按发生顺序）

1. **PowerShell 脚本乱码**：脚本被写成无 BOM 的 UTF-8，`powershell.exe`（5.1）按 ANSI 读取导致解析失败。
   → 修正：所有 `.ps1` 统一写成 UTF-8 with BOM。
2. **数据库「启动成功但连不上」**：`db-start.ps1` 原先把 MySQL 运行目录放在 `%TEMP%`，而每轮 dsh 命令的 TEMP 是独立新目录，命令结束即被清理，库随之消失。
   → 修正：运行目录改为固定路径。
3. **中文路径下 mysqld 起不来**：`mysqld.exe` 会把非 ASCII 路径截断——`--datadir="D:\学习\tools\_run\cr-mysql\data"` 被解析成 `D:\data\`，报 `Failed to set datadir`。相对路径也无效（getcwd 同样被截断）。
   → 修正：运行目录迁到 `C:\carerelay-mysql-root\cr-mysql`（纯 ASCII）。
4. **Flyway V1 建表失败**：`gender VARCHAR(4) DEFAULT 'UNKNOWN'`——`UNKNOWN` 有 7 个字符，超长；`ticket.status VARCHAR(8)` 也放不下 `PROCESSING`。
   → 修正：`gender` 放宽到 `VARCHAR(8)`、`ticket.status` 放宽到 `VARCHAR(16)`，重建库后迁移通过。
