# 选定方向：接力手记（v2）

> 背景：上一版被评价为"很难看"。往年获奖作品的公开口径和 B 站演示视频的封面，是 AI 先扒下来列成一张表的；我逐条看完，
> 结论是那些作品赢在**美术方向明确**，不是赢在组件库多。四个选项我否掉了——这一版不再挑，直接落一套。

## 一、参考看到了什么

| 来源 | 能确认的事实 | 对我们的意义 |
|---|---|---|
| [第八届传智杯一等奖（榆林大学）](https://xxgc.yulinu.edu.cn/info/1054/2652.htm) | 评审口径：AI 深度集成、智能交互、业务完整性 | 功能已够，缺的是"看起来像作品" |
| [第七届一等奖（成都东软）](https://cs.nsu.edu.cn/2025/E0C15257-1590-451C-9A28-D74E226E1C34.html) | 强调围绕具体业务从 0 到 1 闭环 | 主线故事要一眼看出来 |
| B 站第八届获奖演示视频封面（BV1vMdWBhEps、BV12bdxB9EQu） | 两套都是**整屏文化主题海报**：巨幅书法标题 + 满幅实拍 + 极少先现代控件 | 获奖作品的视觉是"排版驱动"，不是"面板驱动" |
| B 站作品讲解视频（BV1kuDWBwEZn） | 用的是通用管理后台，封面就是开发者开 DevTools 的截图 | 这种"后台模板脸"正是我们要避开的 |

> 说明：B 站搜索接口匿名访问被风控（`-412`），视频帧也取不到；上表只依据**封面与标题**，没有假装看过视频内容。

## 二、这一版的语言

一句话：**把系统做成一本被人认真写过的交接手记。**

这张表既是给 AI 的实现说明，也是我验收时逐条对的清单。

| 维度 | 做法 | 为什么 |
|---|---|---|
| 底色 | 暖纸 `#f6f2e9`，卡片 `#fffdf8`，分隔线 `#e2d8c6` | 老人的家、社区的桌面都是暖色；冷灰会立刻显"医院系统" |
| 主色 | 墨绿 `#12433a` / `#1d6b57` | 稳重、不刺眼，和"照护"的语义一致 |
| 语义色 | 朱砂 `#a3342a`（危急）、赭石 `#91621b`（提醒） | 像批注笔，只在"出事了"和"要你做什么"时出现 |
| 标题 | 衬线（Songti/思源宋）+ 字号 34px + 粗细 700 | 报刊感，和"手记"呼应；无衬线会退回后台模板 |
| 数字 | 44px、等宽数位、紧字距 | 护士站台与答辩投影都要隔着一米能念 |
| 卡片 | 16px 圆角、1px 线、几乎无阴影；标题前 4px 短竖条 | 靠"纸、线、留白"分层，不靠投影堆叠 |
| 表格 | 行分隔用虚线，首列加粗 | 像手账横格，行长也能扫读 |
| 侧栏 | 墨绿书脊 + 圆形"A 印章"标 + 选中项＝一张纸签 | 让品牌"接"这个字成为唯一的圆形符号 |

## 三、改了哪些文件

四个文件的改法由我定。我给的是第二节那套语言，外加一句要求：数字要隔一米能念，卡片不许靠阴影堆层次；AI 按这套口径补了样式和页面片段的初稿，我逐处改定后合并。

| 文件 | 改动 |
|---|---|
| `frontend/src/styles/global.css` | 整份重写为 v2 设计系统（tokens、卡片、按钮胶囊、虚线表格、kicker、表单校验） |
| `frontend/src/layouts/AppLayout.vue` | 侧栏改书脊：墨绿渐变、圆形印章标、导航改胶囊纸签、角标改朱砂 |
| `frontend/src/views/LoginView.vue` | 登录页改"封面 + 签到台"：暖纸左页、宋体主标题、赭石短线、演示账号改纸签卡片 |
| `frontend/src/views/WorkbenchView.vue` | 统计数字 34→44px、进度条改纸色底与三档语义色 |

## 附：真的看到了 B 站视频画面（2026-11-08 补）

之前只能拿封面。这次换了个不依赖登录的路子，是 AI 摸出来的：B 站给每条视频都生成了**故事板**（`/x/player/videoshot?bvid=&cid=` 返回一张 10×10 的雪碧图，每格 480×270），拿到图后按格裁出来就是画面。抓帧脚本落在 `.tmp/`，证据图存在 `docs/design/refs/`。

看到的版面（与"后台模板"完全不同）：

| 参考帧 | 看到的 |
|---|---|
| `refs/bili-meishi-hero.png` | 首屏是满幅暗色实拍 + 居中的宋体大标题「食在中国·味在八方」，下面一排三个大数字（282 地标 / 8 大菜系 / 30+ 非遗），主色朱红 |
| `refs/bili-meishi-map.png` | 内容区用"地图 + 卡片列表"双栏，橙红色标签胶囊、圆角卡片、图片压顶 |
| `refs/bili-taoyun-hero.png` | 首屏是 3D/实拍氛围画面（冒热气的茶壶），导航条极窄、文字极小 |
| `refs/bili-taoyun-article.png` | 内容页是**杂志式双栏**：小标题 + 长正文 + 整幅作品图，几乎不用表格 |

据此能直接抄的有三条：

1. **首屏必须有"一句话 + 大字号 + 一排数字"**，不要一上来就是四张统计卡。
2. **内容页用杂志双栏**（小标题 + 短正文 + 图），而不是全表格。
3. **主色只留一个**（他们是一个文化主题色），其余全灰；我们对应的是墨绿 + 朱砂。

字幕仍然拿不到：`/x/player/v2` 匿名返回 `subtitle.subtitles=[]` 且带 `need_login_subtitle`，所以"他们讲了什么"我依旧不知道，只依据画面。
